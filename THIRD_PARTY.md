# Third-party assets and runtime

- **Inter variable font:** `assets/Inter.ttf`, by Rasmus Andersson and contributors; SIL Open Font License 1.1. The complete license is `assets/OFL-Inter.txt`, included in both game packs. Project: https://rsms.me/inter/ ; distribution source: https://github.com/google/fonts/tree/main/ofl/inter . The game uses a local font without contacting a font service.
- **Godot Engine:** official 4.7.2 stable engine/export templates, MIT license. `assets/LICENSE-Godot.txt` and `assets/COPYRIGHT-Godot.txt` are copied unchanged from the official 4.7.2-stable source tag. Both releases include these notices and the font license as readable adjacent files and inside the pack. See https://godotengine.org/license/ .
- **Floating Cities:** Kevin MacLeod (incompetech.com), ISRC USUAN1600018. Original MP3 from https://incompetech.com/music/royalty-free/mp3-royaltyfree/Floating%20Cities.mp3 ; track page: https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1600018&Search=Search . Licensed under Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/ . Included unchanged, with attenuated, faded and looped playback. Attribution is visible in the academy and included as `assets/MUSIC-LICENSE.txt` inside and beside both exports.
- **Icon, academy illustration, topic glyphs, starfields, planets, envelopes, map and interface sounds:** original SVG or vector artwork drawn by repository code (`BureauArt`, `BureauAtlas`, `BureauBackdrop`, `BureauGlyph`); no external image assets. The interface cues use short, smoothly enveloped sine tones.

Teaching references: Princeton Algorithms (https://algs4.cs.princeton.edu/44sp/ and https://algs4.cs.princeton.edu/cheatsheet/) and Red Blob Games A* explanations (https://www.redblobgames.com/pathfinding/a-star/introduction.html and https://www.redblobgames.com/pathfinding/a-star/implementation.html). Hungarian lesson prose and game code were written for this project.

Tree references: University of Wisconsin red-black insertion notes (https://pages.cs.wisc.edu/~ewerner8/) and Dartmouth CS10 balanced-tree notes (https://cs.dartmouth.edu/cs10/notes10.html). Tree code and Hungarian explanations are original implementations; red-black insertion uses the standard symmetric parent/uncle/grandparent fix-up.
